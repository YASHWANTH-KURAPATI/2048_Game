# 2048 — The Neon Puzzle 🎮

A playable, responsive 2048 game with modern visuals. Built with **HTML, CSS, and vanilla JavaScript** — no installation, dependencies, or build tools required.

## Play locally

Open `index.html` in any modern web browser. Use **Arrow Keys**, **WASD**, the on-screen arrow buttons, or **swipe** on a phone.

## Deploy to Vercel (upload a ZIP)

1. Go to https://vercel.com/drop and sign in.
2. Drag the **2048-vercel-ready.zip** file onto the upload area, or browse for it.
3. Follow the prompts to create and publish the project.
4. Vercel will give you a public site link.

You can also upload the project folder after unzipping, or push the files to GitHub and import the repository from https://vercel.com/new.

**Important:** A Tkinter app is a desktop Python GUI and cannot run directly in a web browser. This is a web version of the same 2048 game that can run on Vercel.

## Features

- Fully functional 4 × 4 tile-matching game with correct merge rules
- Keyboard, touch swipe, and on-screen buttons
- Score, best score (saved in your browser), move counter, and tile progress
- Winner and game-over screens with restart and continue options
- Responsive interface, accessible labels, reduced-motion support

## Project files

- `index.html` — page structure
- `styles.css` — responsive design and tile colors
- `script.js` — game logic, controls and score saving
- `favicon.svg` — tab icon
